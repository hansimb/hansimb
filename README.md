## Practical Project Experience

Selected examples of practical projects and studies:

- **Data Engineering & Financial Analytics:** [Macro Valuation Desk](https://github.com/hansimb/macro-valuation-desk) — A local-first research platform for macroeconomic, currency and equity valuation analysis. Includes data pipelines, ETL processes, interactive dashboards, valuation tools and a structured data architecture.
- **Enterprise Systems & Business Processes:** [MiniMRP](https://github.com/hansimb/MiniMRP) — An MRP system for small businesses, covering product management, bills of materials (BOMs), inventory, production planning, material requirements and purchasing. Designed around a local-first architecture with desktop and web application targets.
- **Embedded & Connected Systems:** SOLIS Smart Light — A local-first smart lighting and wake-up light concept combining ESP32 firmware, Bluetooth Low Energy (BLE) communication and a Flutter mobile application. Explores hardware-software integration and connected product architecture.
- **E-commerce & Web Architecture:** [SAI Commerce](https://github.com/hansimb/SAI-commerce-frontend) — A Next.js e-commerce frontend for Spectrum Audio Instruments, integrating Shopify Storefront API. Built with a modular architecture separating UI components and business logic from the underlying content and data source.
- **CMS & Web Platforms:** [Pro Site CMS](https://github.com/hansimb/pro-site-cms) — A full-stack portfolio and content platform built with Next.js, Payload CMS and PostgreSQL. Includes structured content management, case studies, dynamic page composition and SEO functionality.
- **Mobile Application Development:** [FocusBlock](https://github.com/hansimb/focusblock) — A Flutter-based time-blocking and productivity application designed around simplicity and reducing digital distractions. Includes scheduling, notes, to-do lists and locally persisted data.
- **Embedded Software & Hardware Interaction:** [Pedal Controller Prototype](https://github.com/hansimb/pedal-controller-prototype) — An ESP32-oriented hardware controller prototype for managing digital potentiometers, presets and physical controls.
